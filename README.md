# Алина Хатухова — юрист

Сайт-визитка: услуги и цены, сроки, информация о юристе, этапы работы, стоимость, отзывы и контакты.

Статический сайт: один файл `index.html`, без сборки.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Откройте http://localhost:8000.

## Структура

```
index.html     — сайт
assets/img/    — фотографии
assets/docs/   — документы и сертификаты
```
